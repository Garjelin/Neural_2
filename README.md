# Нейронная сеть для распознавания рукописных цифр

Лабораторная работа №5 по дисциплине «Теория нейронных сетей»

## Описание

Программа реализует трёхслойную нейронную сеть для распознавания рукописных цифр (0-9) из базы данных MNIST. Сеть обучается методом стохастического градиентного спуска с использованием алгоритма обратного распространения ошибки.

## Требования

- Python 3.6+
- NumPy
- Pillow (опционально, для визуализации)

## Запуск

### Основной запуск (обучение сети)

```bash
python network.py
```

Программа:
1. Загрузит данные MNIST (50 000 обучающих, 10 000 тестовых примеров)
2. Создаст нейронную сеть с архитектурой 784 → 30 → 10
3. Обучит сеть в течение 30 эпох
4. Выведет точность распознавания после каждой эпохи

### Визуализация (опционально)

```bash
python visualize.py
```

Программа обучит сеть и сохранит PNG-изображения первых 10 тестовых цифр с предсказаниями.

## Параметры обучения

| Параметр | Значение | Описание |
|----------|----------|----------|
| Архитектура | [784, 30, 10] | Входной, скрытый, выходной слои |
| Эпохи | 30 | Количество проходов по обучающей выборке |
| Mini-batch | 10 | Размер подвыборки |
| η (eta) | 3.0 | Скорость обучения |

## Ожидаемый результат

После 30 эпох обучения точность распознавания на тестовой выборке составляет **94-95%**.

Пример вывода:
```
Epoch 0: 6325 / 10000
Epoch 1: 7983 / 10000
...
Epoch 29: 9502 / 10000
```
